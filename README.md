# Robo Assistant

AI-powered robotic assistant for businessmen - SaaS platform for multi-channel business communication automation.

## Features

- Multi-channel communication interface (messengers, email, chat, social media, phone)
- Task automation capabilities (scheduling, email management, document processing)
- Natural language interaction
- Context-aware responses across communication channels

## Demo

Visit the [live demo](https://o2alexanderfedin.github.io/robo-assistant/) deployed on GitHub Pages.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint

# Type check
npm run type-check
```

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- Vite
- Radix UI components
